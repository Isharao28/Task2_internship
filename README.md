# Task 2 - Exploratory Data Analysis on Spotify Dataset

## Objective

To analyze and understand the Spotify dataset using statistical methods and data visualizations.

## Tools Used

* Google Colab
* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Dataset

Spotify Tracks Dataset from Kaggle

## Analysis Performed

* Loaded and explored the dataset
* Checked missing values and data types
* Generated summary statistics
* Created histograms for numerical features
* Visualized outliers using boxplots
* Analyzed feature relationships using pairplots and a correlation matrix
* Identified patterns, trends, and anomalies in the data

## Key Findings

* Most songs have moderate popularity scores.
* Some numerical features contain outliers.
* Several features show positive correlations.
* Genre distribution is uneven across the dataset.

## Conclusion

The analysis provided useful insights into the Spotify dataset and helped understand feature distributions, relationships, and overall data characteristics.
